# Spidey Web OS

A minimal web-based desktop environment built with Next.js. Just a fun project to have a little workspace in the browser.

## What it does

- Desktop interface with draggable windows
- Terminal emulator (simulated)
- Project showcase
- Dashboard with stats
- Photo and sticker layers
- Spider-Man themed because why not

## Live site

Check it out here: [spidey-web-os.vercel.app](https://spidey-web-os.vercel.app)

## Tech

- Next.js 16
- React 19
- Tailwind CSS
- TypeScript

## Running locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Build

```bash
npm run build
npm start
```
